Llanquihue Tour es un sistema automatizado de una agencia de turismo que busca facilitar el trabajo y evitar errores que puedan ocurrir con el registro manual. En este caso se aplica el uso de toString y fromString además del registro y lectura de archivo txt, un ArrayList que captura distintos tours con parametros como nombre, tipo de tour y precio. 
Además cuenta con un menu interactivo con el usuario a traves de la consola usando Scanner para ver los tours disponibles y buscar por caulquiera de los parametros definidos.
